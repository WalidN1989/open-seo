# Integration marks

The SVG brand marks are served locally; opening the catalogue does not send
requests to a logo CDN. Retrieved 2026-09-06.

- Simple Icons: https://github.com/simple-icons/simple-icons/tree/develop/icons
  (claude, googlesheets, hubspot, instagram, make, messenger, shopify,
  woocommerce, zoho). See https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md
- Firecrawl: https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons
  See https://github.com/lobehub/lobe-icons/blob/master/LICENSE

Brand marks remain the property of their respective owners. Webhooks and Custom
API use the application's Lucide symbols; fallback brand names remain visible.
